# 🕒 Tabata Timer PWA

**Tabata Timer** es una aplicación web progresiva (PWA) minimalista y configurable que permite cronometrar rutinas **Tabata** y otros entrenamientos por intervalos.  
Funciona completamente **offline**, se puede **instalar como app** en el celular o computadora, y guarda tus configuraciones en el dispositivo.

---

## 💪 ¿Qué es el método Tabata?

El método **Tabata** es un tipo de entrenamiento por intervalos de alta intensidad (HIIT) que combina **ciclos cortos de ejercicio y descanso**.  
Un ciclo clásico de Tabata consiste en:

- 🏋️‍♂️ 20 segundos de ejercicio  
- ⏸️ 10 segundos de descanso  
- 🔁 8 ejercicios por intervalo  
- 🔂 1 o más intervalos totales  

Esta app te permite **configurar todos esos parámetros**, además de incluir:
- Entrada en calor  
- Cuenta regresiva inicial  
- Enfriamiento (relajo)  

---

## ⚙️ Características principales

✅ Configurable:  
- Número de ejercicios por intervalo  
- Tiempo de ejercicio  
- Tiempo de descanso  
- Cantidad de intervalos  
- Descanso entre intervalos  
- Entrada en calor y enfriamiento  
- Cuenta regresiva antes de iniciar  

✅ Visual y auditiva:  
- Colores distintos para cada fase (ejercicio, descanso, etc.)  
- Sonidos tipo *beep* generados por el navegador  
- Indicadores de progreso y tiempos restantes  

✅ Funcional y moderna:  
- 100% en **HTML, CSS y JavaScript puro**  
- Diseño **responsivo y minimalista**  
- Persistencia con **localStorage**  
- Soporte de **modo oscuro automático**  
- **Instalable como PWA** (funciona offline)  
- **Actualización automática** con aviso cuando hay nueva versión
